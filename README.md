# Pixiv Shaft Remastered

Pixiv Shaft Remastered는 [Pixiv-Shaft](https://github.com/CeuiLiSA/Pixiv-Shaft)를 기반으로 만든 비공식 Android 앱입니다. pixiv에서 제작하거나 운영하는 공식 앱이 아닙니다.

## 설치

[GitHub Releases](https://github.com/ynaru1203/Pixiv-Shaft_Remastered/releases)에서 APK를 받을 수 있습니다.

## 주요 기능

- pixiv 일러스트, 만화, 소설 탐색과 태그 검색, 인기순 미리보기
- 북마크, 팔로우, 열람 기록과 작품 다운로드
- 공식 AI 표시와 태그 규칙을 이용한 AI 작품 숨기기 또는 흐리게 표시
- 다크 모드와 테마 설정

## Remastered 변경 사항

- 한국어 번역을 검수하고 누락된 문구와 숫자 표시 오류를 수정했습니다.
